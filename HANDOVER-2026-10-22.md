## 2. Character → stage recipe (the SDK loop)

The engine is ONE facial engine over any rigged GLB (`GlbAvatar` sniffs
morph names). A character needs geometry + morph targets, nothing else:

```bash
# 1. generate (Meshy — docs/MESHY.md, key in .env, ~20 credits: preview+refine+rig)
curl -s -X POST https://api.meshy.ai/openapi/v2/text-to-3d -H "Authorization: Bearer $MESHY_API_KEY" \
  -H 'Content-Type: application/json' -d '{"mode":"preview","model_type":"smart-topology",
  "pose_mode":"a-pose","prompt":"…A-pose, arms clear of body, facing forward…"}'
#    -> refine (texture; rigging REJECTS untextured meshes) -> /openapi/v1/rigging
# 2. give it a face — Meshy ships ZERO morphs; inject the two the engine reads:
python3 scripts/inject_face_morphs.py model.glb static/avatars/<slug>.glb
#      jawOpen (audio envelope -> he talks) + blink (blink timer). Head-bone-
#      weighted vertex picks; any rigged GLB; rig untouched.
# 2b. verify the binding (PR #10): face:check = per-file verdict (morphs,
#      jaw, eyes — exits non-zero for CI), face:rig = procedural rig
#      fallback, scripts/face_matrix.py = render each emotion -> Qwen
#      vision judges whether the face matches the intent.
# 3. wire it: static/avatars/<slug>.glb  (vite copies -> dist/avatars/)
#    + apps/live/public/sets/index.json entry (set_url, audio_url, avatar_url,
#    beats, duration_ms)
# 4. npm run build && rm -rf edge/dist && cp -r apps/live/dist edge/dist && deploy (§6)
```
Verified: Buddha reports `mouthMode: morph`, `hasBlink: true`, mouth peaks
1.0 on the envelope. Stage rule: no morphs → `none` (never a fake mouth).

## 9. This session's bug zoo (so you don't re-find them)

1. Audio-unlock lag: stage ignored clicks until an 800ms timer set
   `audioLocked` → first click eaten → frozen clock. Now every pointer-down
   unlocks (`StagePage`), `resume()` is idempotent.
2. `bind_addresses: []` (LiveKit) fails startup — omit the key.
3. LiveKit `keys:` map is name→secret, not fields.
4. Auto-dispatch only fires on rooms created **after** worker registration.
5. `pip install livekit-agents[...]` pulls `mcp>=2.2` — breaks quill MCP
   (needs 1.29.0). Pinned back; don't upgrade casually.
6. ffmpeg 5.1.9 rejects `framelog=quiet` in ebur128 → LUFS reads 0.0
   (`packages/audiopost/audiopost/master.py` patched).
7. Rooms on HTTPS probed `http://host:8791` → mixed content; now falls to
   local rooms (`serverOf` returns '' on https without `?server=`).
8. Brand guard scans tracked+untracked files: stale strays must be
   gitignored, placeholders written as `/ABS/<checkout>`.
9. `git add -A` during a merge sweeps stray untracked dirs — stage
   deliberately (`git rm --cached` + amend saved one merge commit).
10. Funner edge caches clips.json 4h; publishing funnier = push repo →
    chars-repo workflow (`funnier.yml`) copies `funnier/site` to gh-pages.
