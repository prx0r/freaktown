# Pogtown Studios — SPLATs, society, and the Christmas season

Characters, not videos, are the enduring assets. The same Dracula does stand-up, podcasts, red carpets, scandal interviews and Christmas specials — and every performance adds to his fictional history.

## The first four SPLATs

### SPLAT 01 — The Comedy Store
One puppet, one microphone, one audience. Stand-up, monologues, hecklers, battles, experiments.
Engine: JokeBlock → SetBuilder → Performance → Audience scoring.

### SPLAT 02 — The Podcast Room
Two to four characters with incompatible worldviews. Dracula and Frankenstein on AI. Pooh interviews The Algorithm. Sherlock investigates Santa.
Engine: CharacterGraph → Dialogue → Interruptions → Callbacks.

### SPLAT 03 — The Interview
Guest, host, increasingly uncomfortable questions. Unlike the podcast: power imbalance — the interviewer has an agenda, the guest has something to conceal.
Engine: Character secrets → Question escalation → Contradictions → Reveal.

### SPLAT 04 — The Red Carpet
Celebrity culture for ridiculous puppets. Betty's controversy. Dracula's 400-year-old girlfriend. Frankenstein demanding representation.
Engine: Reputation → Persona → Scandal → Improvised reaction.

## Christmas season (SPLATs 05–07)

### SPLAT 05 — Santa's Workshop
Workplace sitcom. Santa is management, elves are labour, The Algorithm consults, Popeye leads industrial action.

### SPLAT 06 — Christmas Dinner
Full ensemble, one table. Awkward dynamics, escalating arguments, alliances, revelations.

### SPLAT 07 — The Christmas Awards
Hosted by an increasingly intoxicated Victorian wizard. The Algorithm wins Best Humanitarian.

One fictional event crosses every SPLAT: discussed on podcasts, denied in interviews, confronted on carpets, performed at the Store.

## Architecture (compositional)

CharacterGraph (identity, voice, GLB, relationships, memories) + SPLAT scene (stage, cameras, props, lighting, rules) + JokeBlock/EventGraph (topic, conflict, beats, callbacks) → Performance Director (dialogue, voices, animation, cameras, timing) → episode (YouTube, TikTok, Shorts, interactive Pogtown).

## The Pogtown Times

The fictional world's own publication: creates scandals and recurring stories. Performers reference appearances, hold grudges, run jokes. Pogtown isn't sketches — it's a fictional society whose inhabitants happen to be comedians.

Machine registry: `stage/splats.json`. Familiar characters carry recognition; originals build originality. Particular adaptations/voices/designs still need checking — public domain is not blanket clearance.
