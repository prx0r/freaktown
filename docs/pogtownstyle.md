# Visual design rules

## 1. Silhouette first
Every character should be readable from a black silhouette.

Examples:
- Popeye = huge forearms, tiny cap, pipe
- Dracula = cape triangle + tall collar
- Felix = big head + tail + rubber limbs
- White Rabbit = ears + waistcoat + pocket watch
- Algorithm = box head / screen / angular mechanical body

If the silhouette is strong, the puppet feels iconic.

---

## 2. Materials
Use **shared material logic** across the cast.

### Recommended material families:
- **painted wood**
- **matte resin**
- **felt / cloth accents**
- **lightly worn painted surfaces**
- **paper/card details for props**
- **soft rubber / foam for hands / mouths**

This is huge. It unifies everybody.

So maybe:
- skin/fur/body = matte painted resin
- clothes = felt / cloth
- buttons / props = wood or painted plastic
- eyes = glossy enamel
- mouth interiors = dark felt or matte rubber

That gives tactile identity without needing realism.

---

## 3. Colour system
Keep a **controlled palette**.

Not random saturated colours everywhere.

Use:
- muted vintage tones
- warm neutrals
- theatre reds, dusty blues, moss green, cream, black
- 1 accent colour per character

Example:
- Popeye = navy / cream / faded red
- Dracula = burgundy / black / pale grey
- Felix = black / cream / muted yellow eyes
- Algorithm = charcoal / screen green or cyan
- White Rabbit = cream / dusty lavender / brass

This makes lineups feel curated.

---

## 4. Face design
Faces should be **simple and controllable**.

Best approach:
- large eyes
- sculpted brows or brow plates
- simplified mouth region
- clear cheek / muzzle shapes
- expression readable at a distance

For animation, simpler faces are better than realistic faces.

You want:
- readable smile
- readable suspicion
- readable panic
- readable deadpan
- readable “thinking”

Because comedy depends on instant read.

# Movement style: this is where the magic is

This is the part that separates it from generic generative art.

## The motion should feel:
- slightly stepped
- intentional
- pose-driven
- held for comic effect
- tactile
- theatrical

### Do NOT aim for:
- ultra-smooth mocap realism
- floaty interpolation
- lifeless idle sway
- “default VTuber talking head” feel

### Do aim for:
- clear anticipation
- sharp pose changes
- holds between key poses
- snappy head turns
- strong hand gestures
- asymmetry
- reaction beats

---

# Best animation language

## “Digital stop-motion”
Not literal low FPS jank, but a stylised version of it.

You can get this by:
- animating on 2s or 3s in places
- using stepped holds before transitions
- slightly simplifying in-betweens
- emphasising settle / overshoot only where useful
- keeping some body parts subtly offset so it doesn’t feel dead

So:
- head turns snap
- torso lags slightly
- hands pop into readable poses
- brows hit hard
- mouth keeps moving, but body may hold

This gives the “performed puppet” feel.

# Recommended rig philosophy

You want one shared system.

## Standard puppet rig for most actors:
- root
- hips
- spine
- chest
- neck
- head
- jaw
- upper/lower arms
- hands
- upper/lower legs
- feet
- brows
- eyelids
- eye aim
- mouth corners
- lip open/close
- cheek or muzzle controls if needed
- species extras: ears, tail, cape, antennae, wings

### For GLB specifically
Use:
- **skeletal animation** for body
- **blendshapes / morph targets** for face where useful
- or bone-based facial controls if you want lighter runtime rigs

For web delivery:
- blendshapes for mouth + blink are very useful
- keep the system minimal and reusable

Keep it like filmed puppets.

- waist-up

Pogtown should feel like **performance**, not generic spectacle.
