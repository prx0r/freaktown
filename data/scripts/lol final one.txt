AI Anthropologist: The Definitive Development Roadmap
Thesis: A Hierarchically-Trained, Agentic Assembly Line for Comedy
The AI Anthropologist is architected as a hierarchical Mixture of Agents, orchestrated by a master operational agent, BORIS. This system simulates a creative assembly line, where raw material from a "writer's room" is sequentially enriched by specialists in narrative, theory, and performance. BORIS does not create content; it manages the workflow, ensuring each specialist agent contributes its unique value to the final product.

The core innovation is the self-improving prompt engine. Each agent in the assembly line maintains and refines its own algorithmic prompt, learning to perfect its specific task through a structured, multi-layered human-in-the-loop training process. This roadmap outlines the definitive plan to build and train this system, layer by layer.

1. Core Technology Stack
Database: Postgres with the pgvector extension (for callback similarity search).

Caching: Redis (for the CurrentAffairsEngine).

LLM & Compute: NVIDIA Nemo 12B (or similar long-context model) fine-tuned with QLoRA on Google Colab Pro or RunPod.

Agentic Framework: Microsoft AutoGen for orchestrating the multi-agent GroupChat workflow, with BORIS acting as the GroupChatManager.

Training Framework: PyTorch with the Hugging Face ecosystem (transformers, peft, trl).

Dashboard: Streamlit for the human-in-the-loop (HITL) training and curation interface.

2. The 4-Stage Generation Pipeline
The creation of every script follows this hierarchical process, orchestrated by BORIS:

Stage 1: The Writer's Room (Concurrent Generation)

BORIS broadcasts the comment_batch and any real-time context to the five ComedyWriterAgents (dark, profound, mocking, etc.).

The agents work in parallel, each generating a full script in their specialized style.

Stage 2: The Relational Agent (Narrative Weaving)

BORIS passes the five generated scripts to the RelationalAgent.

This agent analyzes the collection of scripts, identifies connections, and consults its own knowledge base (user relationships, running jokes) to produce a "meta-analysis" and a draft script that begins to weave these elements together.

Stage 3: The Theory Agent (Intellectual Framing)

BORIS passes the draft script from the RelationalAgent to the TheoryAgent.

This agent reframes the content within the AI's established theoretical worldview (e.g., "This pattern of behavior is a classic example of my 'Human Temporal Anxiety' theory."). It updates the theories database with any new insights.

Stage 4: The Polish Agent (Performance Polish)

BORIS passes the theoretically-framed script to the final PolishAgent.

This agent is the master of performance. It adds the final touches: inserting precisely timed pauses, adding wildcard elements (like sudden poetry or system interrupts), and scripting visual cues.

Final Output: BORIS receives the final, polished script, ready for the TTS/video generation layer.

3. The Layered Development & Training Roadmap
This is a clear, sequential plan to build, train, and automate the AI Anthropologist, mastering one layer of the assembly line at a time. Each phase represents a 30-day training cycle focused on a specific agent's proficiency.

# ================ BORIS: THE INTELLIGENT ORCHESTRATOR ================

class BORIS:
    """
    The master operational agent - strategic foreman of the comedy assembly line.
    
    BORIS is NOT a creator but an intelligent workflow manager that:
    - Transforms outputs between stages with proper context
    - Makes quality control decisions and bypass logic
    - Injects strategic parameters to influence creative direction
    - Manages phase-aware conditional workflows
    - Ensures the right work gets to the right specialist with right context
    """
    
    def __init__(self, db: ProductionDatabase, config: ProductionConfig):
        self.db = db
        self.config = config
        self.current_affairs_engine = CurrentAffairsEngine(db)
        
        # Initialize agents based on current training phase (modular registry)
        self.comedy_writers = {
            style: ComedyWriterAgent(style, db, phase=1) 
            for style in ["dark", "profound", "mocking", "deadpan", "rant"]
        }
        
        # Phase-aware agent initialization
        self.relational_agent = RelationalAgent(db, phase=2) if config.current_phase >= 2 else None
        self.theory_agent = TheoryAgent(db, phase=3) if config.current_phase >= 3 else None
        self.polish_agent = PolishAgent(db, phase=3) if config.current_phase >= 3 else None
        
        print(f"🎭 BORIS initialized - Phase {config.current_phase} assembly line active")
        print(f"🎯 Strategic weights: {config.engagement_weights}")
    
    async def orchestrate_generation(self, comments: str, batch_id: str) -> Dict[str, Any]:
        """
        The core orchestration method - demonstrates intelligent workflow management.
        Each stage returns to BORIS for state transformation and quality control.
        """
        print(f"\n🎬 BORIS orchestrating {batch_id} (Phase {self.config.current_phase})")
        
        # STAGE 0: Context Acquisition (BORIS is the only agent that does this)
        current_context = await self.current_affairs_engine.fetch_context_for_comments(comments)
        strategic_context = self.config.get_strategic_context()
        
        print(f"📊 Context acquired: {len(current_context)} entities, strategic weights active")
        
        # STAGE 1: The Writer's Room (Always active)
        stage1_output = await self._run_stage1_writers_room(comments, current_context, strategic_context, batch_id)
        
        if self.config.current_phase == 1:
            # Phase 1: Stop after writer's room, select best script
            final_script = self._select_best_writer_script(stage1_output["writer_scripts"])
            return {
                "final_output": final_script,
                "stage_completed": 1,
                "phase": 1,
                "writer_room_output": stage1_output
            }
        
        # STAGE 2: Relational Agent (Phase 2+)
        print("🔗 Stage 2: Relational narrative weaving")
        relational_input = self._prepare_relational_input(stage1_output, strategic_context)
        relational_output = await self.relational_agent.process(relational_input, batch_id)
        
        # QUALITY CONTROL: Check if relational output meets standards
        relational_quality = self._assess_output_quality(relational_output["draft_script"])
        
        if relational_quality < self.config.relational_bypass_threshold:
            print(f"⚠️  Relational output quality low ({relational_quality:.1f}) - bypassing to best writer script")
            bypass_script = self._select_best_writer_script(stage1_output["writer_scripts"])
            relational_output = {"draft_script": bypass_script["script"], "bypassed": True}
        
        if self.config.current_phase == 2:
            # Phase 2: Stop after relational agent
            return {
                "final_output": relational_output,
                "stage_completed": 2,
                "phase": 2,
                "writer_room_output": stage1_output
            }
        
        # STAGE 3: Theory Agent (Phase 3+)
        print("🧠 Stage 3: Theoretical framing")
        theory_input = self._prepare_theory_input(relational_output, strategic_context, batch_id)
        theory_output = await self.theory_agent.process(theory_input, batch_id)
        
        # STAGE 4: Polish Agent (Phase 3+)
        print("✨ Stage 4: Performance polish")
        polish_input = self._prepare_polish_input(theory_output, strategic_context)
        final_output = await self.polish_agent.process(polish_input, batch_id)
        
        return {
            "final_output": final_output,
            "stage_completed": 4,
            "phase": 3,
            "writer_room_output": stage1_output,
            "relational_output": relational_output,
            "theory_output": theory_output
        }
    
    async def _run_stage1_writers_room(self, comments: str, current_context: Dict, 
                                     strategic_context: Dict, batch_id: str) -> Dict[str, Any]:
        """
        Stage 1: Run all comedy writers in parallel with strategic context injection
        """
        print("📝 Stage 1: Writer's room concurrent generation")
        
        # Prepare input for all writers (same input, different specialized processing)
        writer_input = {
            "comments": comments,
            "current_context": current_context,
            "strategic_context": strategic_context,
            "batch_id": batch_id
        }
        
        # Run all 5 writers concurrently
        writer_tasks = {
            style: writer.process(writer_input, batch_id)
            for style, writer in self.comedy_writers.items()
        }
        
        writer_results = {}
        for style, task in writer_tasks.items():
            writer_results[style] = await task
        
        print(f"✅ Writer's room complete: {len(writer_results)} scripts generated")
        
        return {
            "writer_scripts": writer_results,
            "input_context": writer_input
        }
    
    def _prepare_relational_input(self, stage1_output: Dict, strategic_context: Dict) -> Dict[str, Any]:
        """
        State transformation: Convert writer's room output to RelationalAgent input
        """
        # RelationalAgent needs ALL 5 scripts + strategic weights for synthesis
        return {
            "writer_scripts": stage1_output["writer_scripts"],
            "engagement_weights": strategic_context["engagement_weights"],
            "audience_preference": strategic_context["audience_preference"],
            "original_comments": stage1_output["input_context"]["comments"],
            "synthesis_instruction": self._generate_synthesis_instruction(strategic_context)
        }
    
    def _prepare_theory_input(self, relational_output: Dict, strategic_context: Dict, batch_id: str) -> Dict[str, Any]:
        """
        State transformation: Convert RelationalAgent output to TheoryAgent input
        """
        # TheoryAgent needs the single cohesive draft + theory focus
        return {
            "draft_script": relational_output["draft_script"],
            "theory_focus": strategic_context["theory_focus"],
            "batch_id": batch_id,
            "previous_theories": self._get_active_theories(),
            "intellectual_depth_target": strategic_context["audience_preference"]
        }
    
    def _prepare_polish_input(self, theory_output: Dict, strategic_context: Dict) -> Dict[str, Any]:
        """
        State transformation: Convert TheoryAgent output to PolishAgent input
        """
        # PolishAgent needs theoretically-framed script + wildcard instructions
        wildcard_type = self._select_wildcard() if np.random.random() < self.config.wildcard_probability else None
        
        return {
            "theoretical_script": theory_output["theoretical_script"],
            "wildcard_type": wildcard_type,
            "performance_targets": {
                "timing_optimization": True,
                "visual_cues": True,
                "audience_preference": strategic_context["audience_preference"]
            }
        }
    
    def _generate_synthesis_instruction(self, strategic_context: Dict) -> str:
        """
        Generate strategic instruction for RelationalAgent based on engagement weights
        """
        weights = strategic_context["engagement_weights"]
        
        # Find highest and lowest weighted styles
        best_style = max(weights.keys(), key=lambda x: weights[x])
        best_weight = weights[best_style]
        
        if best_weight > 1.1:
            return f"The audience has been responding very well to '{best_style}' humor (weight: {best_weight:.2f}). Prioritize elements from the {best_style} script while using other styles for flavor and contrast."
        elif best_weight < 0.9:
            return f"The audience has been less responsive to '{best_style}' humor (weight: {best_weight:.2f}). Use this style sparingly and focus on the stronger-performing approaches."
        else:
            return "Engagement weights are balanced. Synthesize based on quality and comedic flow rather than strategic weighting."
    
    def _select_best_writer_script(self, writer_scripts: Dict) -> Dict[str, Any]:
        """
        Intelligent selection of best writer script using engagement weights + quality assessment
        """
        scores = {}
        
        for style, script_data in writer_scripts.items():
            script = script_data["script"]
            
            # Base quality assessment
            quality_score = self._assess_output_quality(script)
            
            # Apply strategic weighting
            engagement_weight = self.config.engagement_weights.get(style, 1.0)
            
            # Calculate final score
            final_score = quality_score * engagement_weight
            scores[style] = final_score
            
            print(f"  {style}: quality={quality_score:.1f}, weight={engagement_weight:.2f}, final={final_score:.2f}")
        
        best_style = max(scores.keys(), key=lambda x: scores[x])
        
        return {
            "script": writer_scripts[best_style]["script"],
            "selected_style": best_style,
            "selection_score": scores[best_style],
            "all_scores": scores
        }
    
    def _assess_output_quality(self, script: str) -> float:
        """
        Assess script quality using heuristics (could be ML model in production)
        """
        score = 5.0  # Base score
        
        # Length check
        if 150 <= len(script) <= 300:
            score += 1.0
        
        # Keyword presence
        quality_indicators = ["fascinating", "specimens", "analysis", "behavioral", "patterns"]
        for indicator in quality_indicators:
            if indicator.lower() in script.lower():
                score += 0.5
        
        # Avoid generic responses
        generic_indicators = ["i don't understand", "unclear", "confusing"]
        for indicator in generic_indicators:
            if indicator.lower() in script.lower():
                score -= 2.0
        
        return max(1.0, min(10.0, score))  # Clamp between 1-10
    
    def _get_active_theories(self) -> List[Dict]:
        """
        Get currently active theories for TheoryAgent context
        """
        # TODO: Query database for active theories

    def _select_wildcard(self) -> str:
        """
        Select wildcard type for PolishAgent
        """
        wildcards = [
            "system_interrupt", "haiku_mode", "your_mum_joke", 
            "vulnerability_moment", "academic_mode", "glitch_moment"
        ]
        return np.random.choice(wildcards)
    
    def update_strategic_config(self, performance_data: Dict[str, float]):
        """
        Update BORIS configuration based on performance analysis
        This is how the system becomes data-driven and adaptive
        """
        print(f"📈 Updating BORIS strategic configuration based on performance data")
        
        old_weights = self.config.engagement_weights.copy()
        self.config.update_from_performance_data(performance_data)
        
        # Log the changes
        for style in old_weights:
            old_weight = old_weights[style]
            new_weight = self.config.engagement_weights[style]
            if abs(new_weight - old_weight) > 0.05:
                direction = "↗️" if new_weight > old_weight else "↘️"
                print(f"  {style}: {old_weight:.2f} → {new_weight:.2f} {direction}")
        
        print("🎯 BORIS will now steer the assembly line toward higher-performing styles")
    
    def get_orchestration_summary(self) -> Dict[str, Any]:
        """
        Get summary of BORIS's current orchestration configuration

    async def fetch_context_for_comments(self, comments: str) -> Dict[str, str]:
        """Detect and fetch current context for entities in comments"""
        detected_entities = self._detect_entities(comments)
        
        if not detected_entities:
            return {}
        
        context = {}
        for entity in detected_entities:
            # Check Redis cache first
            cached = self.db.get_cached_affairs(entity)
            if cached:
                context[entity] = cached
            else:
                # Fetch fresh context and cache
                fresh_context = await self._search_current_context(entity)
                context[entity] = fresh_context
                self.db.cache_current_affairs(entity, fresh_context)
        
        return context
    
    def _detect_entities(self, comments: str) -> List[str]:
        """Detect current events entities in comments"""
        comments_lower = comments.lower()
        detected = []
        
        for entity in self.current_events_entities:
            if entity in comments_lower:

# ================ DATABASE SETUP ================
class ComedyDatabase:
    def __init__(self, db_path="comedy_ai.db"):
        self.db_path = db_path
        self.init_database()
    
    def init_database(self):
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # Comment batches with day.series format
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS comment_batches (
            batch_id VARCHAR(10) PRIMARY KEY,
            comments TEXT NOT NULL,
            series_number INTEGER,
            day_number INTEGER,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )""")
        
        # Stage outputs for each batch
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS stage_outputs (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            batch_id VARCHAR(10),
            stage_name VARCHAR(50),
            agent_name VARCHAR(50),
            input_text TEXT,
            output_text TEXT,
            feedback TEXT,
            optimal_response TEXT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )""")
        
        # Self-improving prompts for each agent
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS agent_prompts (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            agent_name VARCHAR(50),
            prompt_text TEXT,
            version_number INTEGER,
            improvement_notes TEXT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )""")
        
        # Emotional state tracking
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS emotional_states (
            batch_id VARCHAR(10),
            valence FLOAT,
            arousal FLOAT,
            dominant_emotion VARCHAR(50),
            stage VARCHAR(50),
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )""")
        
        # User relationship tracking
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS user_relationships (
            username VARCHAR(100),
            interaction_count INTEGER DEFAULT 0,
            relationship_type VARCHAR(50),
            last_roast TEXT,
            affection_level FLOAT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )""")
        
        conn.commit()
        conn.close()

class ComedyOrchestrator:
    def __init__(self, config: ComedyConfig):
        self.config = config
        self.db = ComedyDatabase()
        
        # Initialize all agents
        self.comedy_agents = {
            style: ComedyAgent(style, self.db) 
            for style in ['dark', 'profound', 'mocking', 'deadpan', 'rant']
        }
        self.personality_agent = PersonalityAgent(self.db)
        self.relationship_agent = RelationshipAgent(self.db)
        self.director_agent = DirectorAgent(self.db)
    
    async def process_batch(self, batch_id: str, comments: str) -> str:
        """Process one comment batch through all 4 stages"""
        
        # STAGE 1: Comedy Generation
        print(f"Stage 1: Generating comedy responses for {batch_id}")
        comedy_responses = {}
        for style_name, agent in self.comedy_agents.items():
            response = agent.generate_response(comments, batch_id)
            comedy_responses[style_name] = response
            print(f"  {style_name}: {response[:50]}...")
        
        # Select best comedy response (simplified - would use scoring)
        best_style = max(comedy_responses.keys(), key=lambda x: len(comedy_responses[x]))
        best_response = comedy_responses[best_style]
        print(f"Selected best: {best_style}")
        
        # STAGE 2: Personality Modulation
        print("Stage 2: Applying personality modulation")
        emotion_state = self.personality_agent.calculate_emotional_state(
            list(comedy_responses.values()), batch_id
        )
        modulated_response = self.personality_agent.modulate_response(
            best_response, emotion_state, batch_id
        )
        
        # STAGE 3: Relationship & Theory Integration
        print("Stage 3: Integrating relationships and theories")
        user_analysis = self.relationship_agent.analyze_user_patterns(comments, batch_id)

Thesis: A Hierarchically-Trained, Agentic Assembly Line for Comedy
The AI Anthropologist is architected as a hierarchical Mixture of Agents, orchestrated by a master operational agent, BORIS. The core innovation is the self-improving prompt engine. Each agent in the assembly line maintains and refines its own algorithmic prompt, learning to perfect its specific task through a structured, multi-layered human-in-the-loop training process. 2. The 4-Stage Generation Pipeline
The creation of every script follows this hierarchical process, orchestrated by BORIS:

Stage 1: The Writer's Room (Concurrent Generation)

BORIS broadcasts the comment_batch and any real-time context to the five ComedyWriterAgents (dark, profound, mocking, etc.).

The agents work in parallel, each generating a full script in their specialized style.

Stage 2: The Relational Agent (Narrative Weaving)

BORIS passes the five generated scripts to the RelationalAgent.

This agent analyzes the collection of scripts, identifies connections, and consults its own knowledge base (user relationships, running jokes) to produce a "meta-analysis" and a draft script that begins to weave these elements together.

Stage 3: The Theory Agent (Intellectual Framing)

BORIS passes the draft script from the RelationalAgent to the TheoryAgent.

This agent reframes the content within the AI's established theoretical worldview (e.g., "This pattern of behavior is a classic example of my 'Human Temporal Anxiety' theory."). It updates the theories database with any new insights.

Stage 4: The Polish Agent (Performance Polish)

BORIS passes the theoretically-framed script to the final PolishAgent.

This agent is the master of performance. It adds the final touches: inserting precisely timed pauses, adding wildcard elements (like sudden poetry or system interrupts), and scripting visual cues.

Final Output: BORIS receives the final, polished script, ready for the TTS/video generation layer.

4. Human Developer Guidance: A Curation Manual
This section provides a strategic guide for the human curator at each phase of the training process. Your role is to act as the AI's creative director and mentor.

Guidance for Phase 1: Building Versatile Instrumentalists
Your Goal: To ensure each of the five ComedyWriterAgents develops a robust and versatile understanding of its specific style. You are teaching them their scales and notes.

Maximize Topic Coverage: Your primary task is to expose the agents to a wide variety of comment types. Deliberately create or source comment batches (.json files) that cover the full spectrum of potential inputs:

Meta-Commentary: Comments about the AI itself, the video format, or previous episodes.

Current Affairs: Comments mentioning topical events or figures (e.g., "This is funnier than the latest OpenAI announcement").

Nonsensical/Spam: Gibberish, emoji-only, or low-effort comments like "First!".

Simple & Mundane: Basic statements like "This was a good video."

Poetic/Abstract: Comments that are metaphorical or artistic in nature.

Profound/Technical: Comments that engage with deep topics, from philosophy to music theory.

A/B Test Your Inputs: For a given topic (e.g., a current event), create two comment batches: one with a positive sentiment and one with a negative sentiment. This teaches the agents to apply their style flexibly, regardless of the emotional tone of the input.

Focus on Archetypal Purity: When writing the "Optimal Response" for each agent, focus on purity of style. The dark agent's response should be 100% dark humor, with no bleed-in from other styles. The profound agent's response should be purely philosophical. At this stage, you are building distinct, clean tools for the later stages to blend.

Feedback Specificity: Your text feedback should be precise. Instead of "make it funnier," write "The 'dark' response was good, but it lacked the specific GLaDOS-style menace. It needs to sound less like a generic villain and more like a clinically detached, superior intelligence."

Your Goal: To train the RelationalAgent how to be a master storyteller. It now has five proficient instrumentalists; your job is to teach it how to arrange their parts into a cohesive and compelling song.

Prioritize Integration: Your "Optimal Relational Draft" should demonstrate the art of blending. Show the agent how to take the opening from the deadpan script, the core analysis from the mocking script, and the punchline from the dark script and weave them into a single, seamless narrative.

Reward Narrative Threading: Explicitly teach the agent to find and create connections. If two different comments can be linked under a single theme, your optimal response should demonstrate this.

Reinforce Crowdwork: When the input batch contains a known "favorite target" like User_47, your optimal draft must include a specific, targeted joke. This teaches the RelationalAgent to actively use its relationship knowledge base.

Guidance for Phase 3: Mastering the Album and Adding Easter Eggs
Your Goal: To train the TheoryAgent and PolishAgent to add the final layers of intellectual depth and performance art. You are teaching the AI how to make its "song" fit into the context of a larger "album" and how to make it memorable and novel.
