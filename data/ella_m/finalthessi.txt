def step_base_linoss(position, velocity, force, dt=0.1):
    omega = 0.1      # Natural frequency
    zeta = 0.05      # Damping coefficient
    
    acceleration = force - (2 * zeta * omega * velocity) - (omega**2 * position)
    velocity_new = velocity + acceleration * dt
    position_new = position + velocity_new * dt
    
    return position_new, velocity_new
```

**Stability Condition:**
```
ζ > 0  (System is stable for any positive damping)

### 1.2 Extended LinOSS (Van der Pol Oscillator)

def step_extended_linoss(position, velocity, force, dt=0.1):
    mu = 0.1         # Van der Pol parameter

def calculate_memory_importance(memory_item, current_time):

    recency = np.exp(-time_diff / 1000)  # Decay constant
