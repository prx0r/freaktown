Samantha Protocol v9.0: The Validated Relational Model
1. High-Level Overview
This document contains the complete technical specifications for building a relational AI based on two core phases: a rigorous Pre-computation & Validation Phase to create scientifically grounded models, and a Live Deployment Phase where the AI learns and evolves through a causal, user-driven feedback loop.

Core Principles:
Validated Foundation: The AI's ability to understand personality is not assumed; it is trained and validated against established psychometric instruments (IPIP-300, HEXACO) to meet a target correlation of r > 0.65.

Trait vs. State: The system models a stable, long-term Personality Trait Profile separately from the fluid, real-time Emotional State of the user.

Annotated Causal Feedback: The AI's personality evolves based on user-bookmarked "Gold Star" moments, which are annotated with natural language to provide a rich, causal learning signal.

Grounded Exploration: The AI has the freedom to explore novel behaviors, which are then reinforced or pruned based on their impact on the relational dynamic, as judged by the user.

2. Phase A: Pre-computation & Validation
This phase must be completed before the main application is deployed for live interaction. It involves two parallel workstreams.

Workstream 1: Training the Validated IPIPProfiler
This directly implements the "Experimental Protocol for H1 Validation" you provided.

Objective: To train and validate a model (IPIPProfiler) that can accurately predict a user's 30-facet IPIP personality scores from a short, open-ended conversation.

Dataset: A dataset of real conversational transcripts, where each participant also has a ground-truth score from the IPIP-300 and HEXACO tests.

Process:

Train the IPIPProfiler model (housed in src/core/analyst.py) to map linguistic and prosodic features from the transcripts to the ground-truth scores.

Rigorously test the model against a hidden validation set.

Success Criterion: The process is complete only when the model's predictions achieve a Pearson correlation of r > 0.65 with the actual test scores, surpassing the current SOTA.

Workstream 2: Training the Foundational Base LoRA
Objective: To give the base DeepSeek model foundational relational skills.

Dataset: A curated dataset of high-quality, empathetic conversations (e.g., anonymized therapy transcripts, counseling sessions, specific podcasts).

Process: Fine-tune the base DeepSeek model on this dataset to create the initial, static Base LoRA. This LoRA teaches the AI the style of introspective, curious, and empathetic communication.

Success Criterion: The LoRA produces coherent, empathetic responses in a style consistent with the training data.

3. Phase B: Live Architecture & Codebase
Once the pre-trained IPIPProfiler and Base LoRA are complete, the live system can be deployed.
