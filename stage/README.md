# Freak Town — Bubble Pop

Canonical bright version: glossy candy bubbles on a soft white stage, using the exact FREAK palette.

Import by copying `web/static/` into the repo root. It is backward-compatible with the current Freak Town server.

The bubble grammar is functional: emotion controls hue, pace controls width, pause controls vertical gap, intensity controls glow/saturation, and timing controls reveal/highlight.

The theme selector is intentionally retained so this build can become Halloween, Christmas, Midnight Carnival or Sticker Freakshow without changing layout code.
